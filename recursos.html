📚 Recursos didàctics

Guies pas a pas per donar-se d'alta, muntar la placa i connectar-la a ThingSpeak.

1. Com donar-se d'alta

  1. Munta la placa i fes que enviï dades a un canal de ThingSpeak (guies 2 i 3).
  2. Fes el canal públic i posa nom als camps (Temperatura, Humitat…).
  3. Obre la pàgina d'alta, tria el tipus de placa i comprova el canal.
  4. Omple el formulari. Una persona responsable l'aprovarà i l'estació sortirà al mapa.

2. Muntatge de la placa

micro:bit amb kit IoT (Wi-Fi)
  1. Connecta la micro:bit a la placa d'expansió del kit i els sensors (temperatura/humitat/pressió, llum, vent) als connectors indicats al manual del kit.
  2. A MakeCode, afegeix l'extensió del fabricant del teu kit (Extensions → cerca el nom del kit o del mòdul Wi-Fi).
  3. Programa: connecta al Wi-Fi (nom i contrasenya de la xarxa del centre) → llegeix els sensors → envia a ThingSpeak amb la Write API Key i un valor per a cada camp.
  4. Fes-ho en un bucle amb una pausa de 60 segons o més (ThingSpeak accepta com a màxim una escriptura cada 15 s).
  5. Camps: field1 temperatura, field2 humitat, field3 llum, field4 pressió, field5 vent. A l'alta tria el perfil «micro:bit amb kit IoT».
ESP32 (Arduino IDE)
  1. Instal·la l'Arduino IDE amb el suport ESP32 i la llibreria Adafruit BME280 (Gestor de llibreries).
  2. Connecta el sensor BME280 per I²C: VIN→3V3, GND→GND, SDA→GPIO 21, SCL→GPIO 22 (en una placa ESP32 DevKit clàssica).
  3. Crea una pestanya secrets.h amb les teves dades. No la pugis mai a git ni la comparteixis. 
    #define WIFI_SSID    "nom-de-la-xarxa"
#define WIFI_PASS    "contrasenya"
#define TS_WRITE_KEY "LA_TEVA_WRITE_API_KEY"
  4. Programa d'exemple (orientatiu; prova'l a la teva placa abans de dependre'n): 
    #include <WiFi.h>
#include <HTTPClient.h>
#include <Adafruit_BME280.h>
#include "secrets.h"

Adafruit_BME280 bme;

void setup() {
  Serial.begin(115200);
  if (!bme.begin(0x76)) Serial.println("BME280 no trobat (prova 0x77)");
  WiFi.begin(WIFI_SSID, WIFI_PASS);
  while (WiFi.status() != WL_CONNECTED) delay(500);
}

void loop() {
  if (WiFi.status() != WL_CONNECTED) { WiFi.reconnect(); delay(5000); return; }
  float t = bme.readTemperature();
  float h = bme.readHumidity();
  float p = bme.readPressure() / 100.0F;   // hPa

  HTTPClient http;
  String url = String("http://api.thingspeak.com/update?api_key=") + TS_WRITE_KEY
             + "&field1=" + t + "&field2=" + h + "&field4=" + p
             + "&field8=" + WiFi.RSSI();
  http.begin(url);
  int code = http.GET();           // 200 = correcte
  Serial.println(code);
  http.end();
  delay(60000);                    // una lectura cada minut
}
  5. Camps: field1 temperatura, 2 humitat, 3 llum (lux), 4 pressió, 5 vent (km/h), 6 pluja (mm), 7 pols, 8 senyal Wi-Fi. A l'alta tria el perfil «ESP32».
  6. L'ESP32 només es connecta a Wi-Fi de 2,4 GHz.
Consells de muntatge a l'exterior
  • Posa el sensor de temperatura a l'ombra i ben ventilat, lluny de l'electrònica (que s'escalfa).
  • Caixa estanca per a la placa; protegeix els connectors de la pluja i la humitat.
  • Contrasta les mesures amb un termòmetre fiable els primers dies.

3. Connexió a ThingSpeak

  1. Crea un compte a thingspeak.com (s'entra amb un compte de MathWorks).
  2. Channels → New Channel. Posa-hi un nom i activa els camps que faràs servir, amb noms clars: Temperatura, Humitat, Pressió…
  3. Desa el canal. Apunta el Channel ID (el número de dalt).
  4. A la pestanya API Keys copia la Write API Key: és la que posa la placa al programa. Mai no la comparteixis.
  5. A la pestanya Sharing, marca Share channel view with everyone perquè el canal sigui públic.
  6. Encén la placa: en uns minuts hauries de veure punts al gràfic del canal.
  7. Comprova'l a la pàgina d'alta amb el Channel ID.

Límits i condicions del compte gratuït (interval d'escriptura, missatges l'any, nombre de canals): consulta-los a la documentació de ThingSpeak, poden canviar.

4. Si alguna cosa no funciona

  • El canal no té dades: revisa que la placa tingui Wi-Fi i que la Write API Key sigui la correcta. Un codi 200 a la resposta vol dir que s'ha acceptat.
  • No es connecta a la xarxa del centre: comprova que sigui de 2,4 GHz i parla amb el coordinador digital (pot haver-hi filtratge o registre de dispositius).
  • Els valors surten estranys: mira que el camp correspongui al sensor correcte i el perfil triat a l'alta.
  • Més dubtes: escriu-nos des de Contacte.
